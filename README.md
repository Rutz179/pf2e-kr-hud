# Rutz's PF2e HUD

Party portraits with voice highlighting and a per-character quick-slot HUD for Pathfinder 2e.

- **Party portraits** — up to 6 PCs on either side of the screen, HP bars, the speaker highlighted through Discord voice or Foundry A/V.
- **Quick slots** — 10 slots × up to 3 rows × 4 pages with hotkeys: macros, items, spells, Strikes, skills and PF2e actions.
- **Combat at a glance** — effect rings, action pips (reference), saves and spell DC.
- **Locking** — editing is for the GM, the character's player, and whoever the GM allows.

## Install
Foundry → *Add-on Modules* → *Install Module* → Manifest URL:
```
https://github.com/Rutz179/pf2e-kr-hud/releases/latest/download/module.json
```
