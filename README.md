# PF2e-KR 파티 HUD (v0.8.0)

설치 주소(매니페스트): `https://github.com/Rutz179/pf2e-kr-hud/releases/latest/download/module.json`

## 배포 (CoC 툴킷과 같은 방식)
```bash
git tag v0.4.1
git push origin v0.4.1
```
태그를 올리면 GitHub Actions가 버전·주소를 채운 module.json과 module.zip을 릴리스에 올립니다.
module.json의 version은 손으로 고칠 필요가 없습니다.


Foundry VTT v14 + PF2e 전용. CoC7 한국어 툴킷의 초상화 배치와 디스코드 음성 연동을
PF2e로 옮기고, 캐릭터별 퀵슬롯 HUD를 새로 붙였습니다.

## 파티 초상화
- PC 최대 6명, CoC 툴킷과 같은 자리(왼쪽/오른쪽 × 위/가운데/아래). NPC는 표시하지 않습니다.
- 자리 배치: 모듈 설정 → *파티 초상화 자리 배치* (비우면 플레이어 할당 캐릭터 자동 배치)
- 초상화 아래 작은 HP 막대. 숫자는 설정에서 소유자만/모두/숨김
- **초상화 모양 → "이미지만"**: 반투명 판·테두리를 없애 그림만 보입니다 (투명 PNG 권장)
- 말하는 사람 강조: 디스코드 음성 브리지(설정 도우미 포함) 또는 Foundry 자체 A/V
- 클릭: 소유자는 토큰 선택 / 그 외는 관찰 카드 · 더블클릭: 시트

## 캐릭터 HUD
- 보이는 대상: 선택한 토큰(소유 권한 필요). 플레이어는 선택이 없으면 할당된 캐릭터
- 관찰자 권한 대상: 토큰을 **타깃(T)** 하거나 초상화를 클릭하면 HP·효과만 있는 작은 카드
- 퀵슬롯 10칸 × 1~3줄 × 4페이지 (휠 또는 `[` `]`로 페이지)
  - 단축키: 1줄 `1~0`, 2줄 `Shift+1~0`, 3줄 `Alt+1~0` (조작 설정에서 변경 가능)
  - 올릴 수 있는 것: 매크로, 이 캐릭터의 아이템/주문/피트, 공격(Strike), 기술 굴림, PF2e 시스템 액션
  - 기술·액션(잡기, 사기저하, 회피 돌파, 지식 회상 등)은 **잠금을 풀고 빈칸 클릭** → 목록에서 선택
  - 쓸 수 없는 상태(수량 0, 무기 미장비, 집중 포인트 0)는 흐리게, 사라진 대상은 ✕
  - 소모품은 클릭 시 카드만 올림(실수 방지). 바로 소비는 Shift+클릭
  - 공격: 클릭 1타, Shift 2타, Alt 3타 (단축키는 항상 1타)
- **잠금 (BG3식)**: 기본 잠김. 편집 권한 = GM + 그 캐릭터를 할당받은 유저 + GM이 허용한 유저
  (소환수·에이돌론용: GM에게만 보이는 사람 아이콘 → 편집 권한)
- 주입(Infused) 아이템 자동 배치/자동 제거 (연금술사)
- HP 막대 위 효과 동그라미: 좌클릭 +1, 우클릭 −1/제거. PF2e 기본 효과 패널은 숨김(설정)
- 행동 동그라미 3 + 추가 1(신속일 때 활성) + 되돌리기. **참조용이며 아무것도 막지 않음**.
  감속이면 앞 칸이 빗금. 턴 시작 시 자동 초기화(설정)
- 가운데 내성/주문 DC 버튼 → 시트의 액션 탭. 좌우 작은 버튼 → 인벤토리 / 주문·피트 훑어보기

## 처음 확인해 볼 것 (실제 Foundry에서 아직 검증 전)
1. PC 토큰 선택 → HUD 표시, `1`키로 슬롯 실행
2. 시트에서 주문/아이템/무기 공격을 끌어 슬롯에 놓기 (잠금 해제 상태)
3. 빈칸 클릭 → 목록에 PF2e 액션이 나오는지 (`game.pf2e.actions`)
4. 액션 탭 버튼이 해당 탭을 여는지
5. 소유권 있는 다른 플레이어가 배치를 못 바꾸는지

## 디스코드 음성 브리지
`tools/discord-voice-bridge` — CoC 툴킷과 동일 (pm2 이름만 `pf2e-kr-voice-bridge`).
설정 → *디스코드 음성 연동 설정 도우미*를 쓰세요.

## v0.2.0 변경점
- HUD: 화면 너비에 맞춰 칸 크기 자동(42~64px) + 설정 `HUD 크기` 배율. 글자는 Foundry 글꼴 크기 설정을 따름(rem)
- 1줄일 때 위아래 여백 최소화(옆 버튼 2×2 배치), 줄 수에 따라 높이만 늘어남
- 마지막으로 선택한 내 토큰이 계속 유지됨. Foundry 기본 매크로 바는 기본으로 꺼짐
- 공격 슬롯: 클릭 = 이번 턴 공격 횟수에 맞춘 MAP 자동, 우클릭 2타, 휠클릭 3타, Shift 1타. 배지에 다음 공격 수치
- 인내/반사/의지 누르면 굴림. 주문 DC(없으면 클래스 DC) 누르면 채팅에 내성 굴림 요구 카드(@Check 버튼)
- 시트 액션 탭은 오른쪽 아래 달리는 사람 아이콘
- 행동 동그라미: pf2e-auto-action-tracker가 켜져 있으면 그 기록과 연동(신속 포함), 없으면 채팅의 공격/액션 굴림으로 자동 계산. 주문·피트 카드를 채팅에 올리는 것은 세지 않음
- 효과 아이콘 32px, 잠시 올려두면 설명 카드(오른쪽 위 채팅 보내기 버튼)
- 초상화: GM 설정으로 모두에게 표시, 평소 회색 흐림 → 음성/채팅 시 밝아짐 + 말풍선, 아래 여백 설정, 클릭 기능 제거
- GM 토큰 도구 막대에 초상화 배치 편집(끌기/휠 크기), 자리 배정, 배치 초기화, 표시 켜기/끄기

## v0.3.0 변경점
- 왼쪽 도구 막대에 **러츠 툴킷** 탭 하나: 초상화 관리(GM) · 내 초상화 표정 · 귓속말 창 · 공유 노트 창 · 디스코드 음성 연동(GM)
- 초상화 관리 창 하나로 통일: 표시, 말풍선, 자리 배정, 배치 편집/초기화, 자리별 표정
- 초상화 표정(코코포리아식): 캐릭터별 최대 5개. 채팅에 `@키워드` → 표정 변경(키워드는 메시지에서 삭제), `@기본`으로 복귀
- CoC 툴킷의 채팅 묶기(같은 화자 연속 발언 통합), 귓속말 창, 공유 노트 창 이식. GM 귓속말 창은 접속 중인 플레이어만, 버튼으로 미접속자 포함
- 접속자 목록을 작은 아이콘으로 접기(기본)
- 하단 바: AC · 인내 · 반사 · 의지 · 지각 (+ 시전자면 주문 DC). 클래스 DC 제거
  - 내성 클릭 = 굴림 + "인내 DC 26"(10+수정치) 카드. 설정에서 카드 끄기 가능
- 행동: 클릭하면 항상 다음 행동(왼→오), 우클릭 되돌리기, Shift+클릭 추가 행동 부여/회수. 트래커의 actionsSpent 직접 사용
  - 콘솔 진단: `game.pf2eKrHud.debugEconomy()`
- 효과 42px, Shift+클릭으로 한 번에 제거, 설명 카드 글씨 작게
- 소모품이 0개가 되거나 PF2e가 지워도 슬롯은 회색으로 남고, 다시 생기면 자동으로 다시 연결
- 이름에서 "(Level N)" 제거, 초상화 HP 숫자 크게, 전신 이미지가 위 카드 이름을 가리지 않게 실제 높이 측정
- 기본 HUD 크기 1.1

## v0.3.1 (긴급 수정)
- 채팅 묶기: 직접 타이핑한 일반 채팅만 묶음. 주문·공격·아이템 카드와 굴림은 PF2e 모양 그대로(헤더 겹침/이중 출력 수정). 채팅 아바타·사용자 이름 추가는 기본 끔
- 귓속말 범위 3단계: GM하고만 / 플레이어끼리 + GM 항상 참조 / 플레이어끼리 GM 없이
- 공격 슬롯: 클릭(또는 단축키) → 1타/2타/3타 선택 창, 피해·크리티컬은 채팅 카드에서
- NPC: 퀵슬롯이 비어 있으면 GM이 처음 선택할 때 공격→액션→주문 자동 채우기(설정), 요술봉 버튼으로 언제든
- NPC 공격(melee 아이템)을 끌어 놓으면 공격 슬롯으로
- 행동 카운트(트래커 없을 때): 시트의 '캐스트' 버튼과 퀵슬롯 사용은 셈, 주문·피트 창에서 채팅에 올리기는 안 셈
- PF2e '인카운터 중 조건 보기'(턴마다 현재 상태 카드)를 월드당 한 번 자동으로 끔
- 초상화 관리 창이 두 개 뜨던 문제, 러츠 툴킷 탭의 중복 아이콘, 디스코드 아이콘 깨짐 수정
- @표정: 토큰 없이 쳐도 HUD 캐릭터로 적용, "@ 웃음"처럼 띄어 써도 인식
- 접속자 목록: 아이콘을 누르면 원래 자리에 잠깐 펼쳐졌다가 자동으로 접힘

- 시간 조절(GM이 시계 클릭): ±10분·±1시간·+8시간, 아침/정오/저녁/자정, 시각 직접 지정
- 시간에 맞춰 장면 조명(어둠) 자동 조절 — SmallTime 없이. 장면별로 끄기 가능. PF2e 월드 시계 동기화가 켜져 있으면 그쪽 우선
- GM 굴림 요청: 지각·내성·기술을 골라 DC(레벨 DC 도우미 포함)·비밀·기본 내성·설명과 함께 카드 전송, 또는 매크로로 저장
- GM 팔레트: 매크로·효과·상태를 올려두고 선택한 토큰들에 바로 적용 (3×2 ~ 6×2, 반투명, 잠금·이동)
- NPC 등 HP를 볼 수 없는 토큰에 마우스를 올리면 '가벼운 부상' 같은 체력 상태 (단계·이름 설정 가능)
- 효과: 카운터가 있는 효과도 좌클릭 +1 / 우클릭 −1, 설명 카드에 편집(연필) 버튼
- 하단 바에서 주문 DC 제거

## v0.8.0 — 반응(리액션) 알림 (pf2e-reaction · socketlib 대체)
- 적의 이동·원거리 공격/주문·나를 향한 공격·공격 대실패·피해·아군 피해·내성 굴림에서 쓸 수 있는 반응을 찾아 채팅 카드로 알림
- 받는 사람: 그 캐릭터를 **할당받은 플레이어 + GM**만 (소유권만 있는 사람 제외). NPC는 GM만. 캐릭터별로 받는 사람 지정 가능
- 카드에 '리액션 1/1' 표시, 쓸 수 있는 반응이 여러 개면 모두 버튼으로. 화면 위 팝업(설정)
- [사용] → 모두가 보는 "○○이 반응 ○○을 사용" 메시지 + 공격형 반응은 바로 공격 굴림(무기가 여럿이면 선택)
- [반응 안 함] → GM·받는 사람에게 알림. 답하면 카드가 닫혀 두 번 답할 수 없음
- 자동 인식 약 35종(반응 타격, 방패 막기, 민첩한 회피, 응징의 일격 등) + 러츠 툴킷 → 반응 설정에서 반응별 트리거·범위·공격 여부 조절
- 소켓 라이브러리 불필요: 감지는 GM 화면 하나에서만, 나머지는 채팅 카드와 플래그로 처리
