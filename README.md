# Rutz's PF2e HUD

PF2e용 파티 초상화와 캐릭터별 퀵슬롯 HUD.
*Party portraits with voice highlighting and a per-character quick-slot HUD for Pathfinder 2e.*

- **파티 초상화** — PC 최대 6명, 화면 좌우에 배치, HP 막대, 디스코드 음성 연동이나 Foundry A/V로 말하는 사람 강조.
- **퀵슬롯 HUD** — 10칸 × 최대 3줄 × 4페이지, 단축키. 매크로·아이템·주문·공격·기술·PF2e 액션을 올립니다.
- **잠금** — 편집 권한은 GM, 그 캐릭터의 플레이어, GM이 허용한 사람.
- **전투 보조** — 효과 동그라미, 행동 동그라미(참조용), 내성·주문 DC 요약.
