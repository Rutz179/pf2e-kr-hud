# PF2e-KR 파티 HUD (v1.3.0)

설치 주소(매니페스트): `https://github.com/Rutz179/pf2e-kr-hud/releases/latest/download/module.json`

## 배포 (CoC 툴킷과 같은 방식)
```bash
git tag v0.4.1
git push origin v0.4.1
```
태그를 올리면 GitHub Actions가 버전·주소를 채운 module.json과 module.zip을 릴리스에 올립니다.
module.json의 version은 손으로 고칠 필요가 없습니다.


Foundry VTT v14 + PF2e 전용. CoC7 한국어 툴킷의 초상화 배치와 디스코드 음성 연동을
PF2e로 옮기고, 캐릭터별 퀵슬롯 HUD를 새로 붙였습니다.

## 파티 초상화
- PC 최대 6명, CoC 툴킷과 같은 자리(왼쪽/오른쪽 × 위/가운데/아래). NPC는 표시하지 않습니다.
- 자리 배치: 모듈 설정 → *파티 초상화 자리 배치* (비우면 플레이어 할당 캐릭터 자동 배치)
- 초상화 아래 작은 HP 막대. 숫자는 설정에서 소유자만/모두/숨김
- **초상화 모양 → "이미지만"**: 반투명 판·테두리를 없애 그림만 보입니다 (투명 PNG 권장)
- 말하는 사람 강조: 디스코드 음성 브리지(설정 도우미 포함) 또는 Foundry 자체 A/V
- 클릭: 소유자는 토큰 선택 / 그 외는 관찰 카드 · 더블클릭: 시트

## 캐릭터 HUD
- 보이는 대상: 선택한 토큰(소유 권한 필요). 플레이어는 선택이 없으면 할당된 캐릭터
- 관찰자 권한 대상: 토큰을 **타깃(T)** 하거나 초상화를 클릭하면 HP·효과만 있는 작은 카드
- 퀵슬롯 10칸 × 1~3줄 × 4페이지 (휠 또는 `[` `]`로 페이지)
  - 단축키: 1줄 `1~0`, 2줄 `Shift+1~0`, 3줄 `Alt+1~0` (조작 설정에서 변경 가능)
  - 올릴 수 있는 것: 매크로, 이 캐릭터의 아이템/주문/피트, 공격(Strike), 기술 굴림, PF2e 시스템 액션
  - 기술·액션(잡기, 사기저하, 회피 돌파, 지식 회상 등)은 **잠금을 풀고 빈칸 클릭** → 목록에서 선택
  - 쓸 수 없는 상태(수량 0, 무기 미장비, 집중 포인트 0)는 흐리게, 사라진 대상은 ✕
  - 소모품은 클릭 시 카드만 올림(실수 방지). 바로 소비는 Shift+클릭
  - 공격: 클릭 1타, Shift 2타, Alt 3타 (단축키는 항상 1타)
- **잠금 (BG3식)**: 기본 잠김. 편집 권한 = GM + 그 캐릭터를 할당받은 유저 + GM이 허용한 유저
  (소환수·에이돌론용: GM에게만 보이는 사람 아이콘 → 편집 권한)
- 주입(Infused) 아이템 자동 배치/자동 제거 (연금술사)
- HP 막대 위 효과 동그라미: 좌클릭 +1, 우클릭 −1/제거. PF2e 기본 효과 패널은 숨김(설정)
- 행동 동그라미 3 + 추가 1(신속일 때 활성) + 되돌리기. **참조용이며 아무것도 막지 않음**.
  감속이면 앞 칸이 빗금. 턴 시작 시 자동 초기화(설정)
- 가운데 내성/주문 DC 버튼 → 시트의 액션 탭. 좌우 작은 버튼 → 인벤토리 / 주문·피트 훑어보기

## v1.3.0 — 골라리온 달력 · 턴 트래커 · 퀵슬롯 설명 카드
- 채팅창 시계: 실제 달력("2026년 5월 11일") 대신 **게임 세계의 날짜**를 표시합니다.
  예) `골라리온력 4726년 5월 11일 문데이`. PF2e 월드 시계의 날짜 테마(압살롬력·제국력·서기)와
  연도 보정을 그대로 따르며, 마우스를 올리면 골라리온 달 이름(데스누스 등)이 보입니다.
- 시각은 **오전/오후 12시간제**(`오후 3:05`). 설정에서 24시간제로 바꿀 수 있습니다.
- GM에게만 시계 아래 **−1일 · −1시간 · −10분 · +10분 · +1시간 · +1일** 버튼. 날짜를 누르면 예전처럼
  시각 지정·장면 조명 설정 창이 열립니다.
- 체력 상태 표시를 토큰 **아래**로 옮겼습니다. 토큰 이름표가 있으면 그 아래에 간격을 두고 놓아
  이름을 가리지 않습니다. 토큰 사이 거리를 가리던 문제가 없어집니다.
- 체력 상태 색: 단계마다 고유한 색(초록 → 노랑 → 주황 → 빨강)을 쓰고, **같은 단계 안에서도 HP가
  낮을수록 더 진하고 어두운 색**이 됩니다. 같은 '심한 부상'이라도 더 심한 쪽이 한눈에 보입니다.
- 퀵슬롯 주문: 누르면 **[시전] / [채팅으로 보내기] / [시트]** 창이 뜹니다. 시전은 시트처럼 슬롯·집중
  점수·선천 횟수를 쓰고(준비형은 준비한 랭크별, 자연 시전형은 남은 슬롯 표시, 고유 주문은 상위 랭크
  선택), 채팅으로 보내기는 아무것도 쓰지 않고 카드만 올립니다. 슬롯이 없을 때도 채팅으로는 보낼 수 있습니다.
- **퀵슬롯 설명 카드**: 퀵슬롯에 마우스를 잠시(기본 0.8초, 0.5~1.5초 설정) 올려두면 행동 비용·특성·
  랭크/레벨·사거리·방어·설명이 담긴 카드가 뜹니다. 시트를 열지 않아도 됩니다. 설정에서 끌 수 있습니다.
- **턴 트래커** (화면 위, 발더스 게이트 3 방식): 지금 차례인 전투원부터 순서대로 초상화가 늘어서고,
  다음 라운드가 시작되는 자리에 `R3` 같은 표시가 들어갑니다. 지금 차례는 크게 금테로, 이름과 함께.
  초상화 아래쪽 띠 색으로 아군(파랑)·적(빨강)·중립(노랑)을 구분하고, 우선권 숫자를 표시합니다.
  - GM: 우선권 모두 굴리기 · NPC만 굴리기 · 전투 시작 · 이전/다음 차례 · 전투 종료.
    초상화 우클릭 = 쓰러짐 표시, Shift+우클릭 = 숨기기
  - 플레이어: 아직 안 굴린 내 캐릭터의 주사위 아이콘 또는 [내 우선권 굴리기], 내 차례에 [턴 종료]
  - 쓰러진 전투원은 **회색으로 남기거나 숨기기**(월드 설정)
  - 초상화를 누르면 그 토큰으로 화면 이동, 내 토큰이면 선택
  - 가볍게 만들었습니다: 템플릿·체력/방어도 툴팁 없음, 전투가 바뀔 때만 다시 그림, 초상화 이미지는
    다시 불러오지 않고 재사용. PF2e에 의존하지 않아 공용 UI 모듈로 그대로 옮길 수 있습니다.
  - Carousel Combat Tracker가 켜져 있으면 표시하지 않습니다. 이 트래커를 쓰려면 그 모듈을 꺼 주세요.
