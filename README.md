# Rutz's PF2e HUD (v1.6.0)

설치 주소(매니페스트): `https://github.com/Rutz179/pf2e-kr-hud/releases/latest/download/module.json`

## 배포 (CoC 툴킷과 같은 방식)
```bash
git tag v0.4.1
git push origin v0.4.1
```
태그를 올리면 GitHub Actions가 버전·주소를 채운 module.json과 module.zip을 릴리스에 올립니다.
module.json의 version은 손으로 고칠 필요가 없습니다.


Foundry VTT v14 + PF2e 전용. CoC7 한국어 툴킷의 초상화 배치와 디스코드 음성 연동을
PF2e로 옮기고, 캐릭터별 퀵슬롯 HUD를 새로 붙였습니다.

## 파티 초상화
- PC 최대 6명, CoC 툴킷과 같은 자리(왼쪽/오른쪽 × 위/가운데/아래). NPC는 표시하지 않습니다.
- 자리 배치: 모듈 설정 → *파티 초상화 자리 배치* (비우면 플레이어 할당 캐릭터 자동 배치)
- 초상화 아래 작은 HP 막대. 숫자는 설정에서 소유자만/모두/숨김
- **초상화 모양 → "이미지만"**: 반투명 판·테두리를 없애 그림만 보입니다 (투명 PNG 권장)
- 말하는 사람 강조: 디스코드 음성 브리지(설정 도우미 포함) 또는 Foundry 자체 A/V
- 클릭: 소유자는 토큰 선택 / 그 외는 관찰 카드 · 더블클릭: 시트

## 캐릭터 HUD
- 보이는 대상: 선택한 토큰(소유 권한 필요). 플레이어는 선택이 없으면 할당된 캐릭터
- 관찰자 권한 대상: 토큰을 **타깃(T)** 하거나 초상화를 클릭하면 HP·효과만 있는 작은 카드
- 퀵슬롯 10칸 × 1~3줄 × 4페이지 (휠 또는 `[` `]`로 페이지)
  - 단축키: 1줄 `1~0`, 2줄 `Shift+1~0`, 3줄 `Alt+1~0` (조작 설정에서 변경 가능)
  - 올릴 수 있는 것: 매크로, 이 캐릭터의 아이템/주문/피트, 공격(Strike), 기술 굴림, PF2e 시스템 액션
  - 기술·액션(잡기, 사기저하, 회피 돌파, 지식 회상 등)은 **잠금을 풀고 빈칸 클릭** → 목록에서 선택
  - 쓸 수 없는 상태(수량 0, 무기 미장비, 집중 포인트 0)는 흐리게, 사라진 대상은 ✕
  - 소모품은 클릭 시 카드만 올림(실수 방지). 바로 소비는 Shift+클릭
  - 공격: 클릭 1타, Shift 2타, Alt 3타 (단축키는 항상 1타)
- **잠금 (BG3식)**: 기본 잠김. 편집 권한 = GM + 그 캐릭터를 할당받은 유저 + GM이 허용한 유저
  (소환수·에이돌론용: GM에게만 보이는 사람 아이콘 → 편집 권한)
- 주입(Infused) 아이템 자동 배치/자동 제거 (연금술사)
- HP 막대 위 효과 동그라미: 좌클릭 +1, 우클릭 −1/제거. PF2e 기본 효과 패널은 숨김(설정)
- 행동 동그라미 3 + 추가 1(신속일 때 활성) + 되돌리기. **참조용이며 아무것도 막지 않음**.
  감속이면 앞 칸이 빗금. 턴 시작 시 자동 초기화(설정)
- 가운데 내성/주문 DC 버튼 → 시트의 액션 탭. 좌우 작은 버튼 → 인벤토리 / 주문·피트 훑어보기

## 처음 확인해 볼 것 (실제 Foundry에서 아직 검증 전)
1. PC 토큰 선택 → HUD 표시, `1`키로 슬롯 실행
2. 시트에서 주문/아이템/무기 공격을 끌어 슬롯에 놓기 (잠금 해제 상태)
3. 빈칸 클릭 → 목록에 PF2e 액션이 나오는지 (`game.pf2e.actions`)
4. 액션 탭 버튼이 해당 탭을 여는지
5. 소유권 있는 다른 플레이어가 배치를 못 바꾸는지

## 디스코드 음성 브리지
`tools/discord-voice-bridge` — CoC 툴킷과 동일 (pm2 이름만 `pf2e-kr-voice-bridge`).
설정 → *디스코드 음성 연동 설정 도우미*를 쓰세요.




## v1.12.0 — 긴 세션 렉 · 일괄 피해 · 반응 정리 · 지속 주문 · 효과 시간

- **채팅 정리 (긴 세션 렉 줄이기)**: 화면에는 최근 카드 80장(설정)만 남기고 오래된 카드는 페이지에서 내려 둡니다(메시지 자체는 그대로).
  위로 스크롤하면 순서대로 다시 불러오고, 내려 둔 카드가 갱신돼도(툴벨트 '적용됨' 표시 등) 맨 아래로 튀어나오지 않습니다.
  **Less Chat 모듈과 같은 역할이라 Less Chat이 켜져 있으면 HUD 쪽 정리는 자동으로 쉽니다.** 둘 중 하나만 쓰세요(HUD 쪽 권장 — Less Chat은 Foundry 채팅 내부를 통째로 갈아 끼워서 메시지가 안 보이는 문제의 원인이 될 수 있습니다).
- **↓ 버튼**: 채팅을 위로 올려 보고 있으면 채팅창 오른쪽 아래에 작은 ↓ 버튼이 뜹니다. 누르면 가장 최근 메시지로.
- **피해 '모두 적용' (PF2e Toolbelt)**: 툴벨트 대상 목록이 붙은 피해 카드 위에 GM만 보이는 버튼 하나.
  각 대상의 내성 결과대로 대실패 ×2 · 실패 ×1 · 성공 ×½ · 대성공 없음을 한 번에 적용합니다(툴벨트 자기 버튼을 차례로 눌러서 IWR·적용됨 표시도 그대로).
  아직 내성을 굴리지 않은 대상은 빼고 적용하고 버튼에 '내성 대기 n'으로 알려 줍니다. 회복 굴림이면 '모두 회복'.
- **반응 알림 정리**: 한 사건에 여러 명이 반응할 수 있으면 GM에게는 **카드 한 장**(누가 무엇을 쓸 수 있는지, 누가 골랐는지)만 가고,
  플레이어는 각자 자기 작은 카드/팝업을 받습니다. 토큰 이동은 멈춘 뒤 한 번만 판단하고, 같은 턴에 같은 상대로는 다시 묻지 않습니다.
  **숨김 토큰**(아직 공개 전이거나 죽어서 숨긴 토큰)과 쓰러진/전투에서 패배 처리된 적은 반응을 일으키지도, 반응하지도 않습니다.
- **방패 막기**: 규칙(플레이어 코어) 그대로 '방패를 든 상태에서 **물리 공격**으로 피해를 받을 때'만 묻습니다 —
  공격 굴림에서 나온 타격/관통/참격 피해만. 지속 피해, 내성 주문(화염구 등), 에너지 피해만 있는 경우에는 묻지 않습니다.
  방패 막기를 고르면 이미 적용된 피해를 **자동으로 되돌리고**, 그 대상만 남긴 피해 카드를 GM에게 다시 띄웁니다 — 방패 버튼을 켜고 다시 적용하면 됩니다.
- **지속 주문 (pf2e-sustain-reminder 대체)**: 지속 주문을 쓰면 시전자에게 '지속: 주문' 효과가 붙고,
  그 캐릭터 턴이 시작될 때 플레이어와 GM에게 귓속말 카드로 **지속(1행동) / 끝내기**를 묻습니다.
  지속 → HUD 행동 점 하나가 사용됨으로, 끝내기 → 그 주문이 건 효과들이 함께 사라집니다. 원래 모듈은 꺼 주세요.
- **반응 점**: 전투 중 HUD 행동 점 옆에 파란 반응 점(↩). 반응을 '사용'하면 자동으로 채워지고, 클릭/우클릭으로 고칠 수 있으며 내 턴이 시작되면 돌아옵니다.
- **효과 남은 시간**: 효과 동그라미 둘레에 남은 시간만큼 테두리가 줄어들고, 위에 작은 글자(3R · 8분 · 1시간 · 전투)가 붙습니다.
  마우스를 올리면 정확한 값: "7분 24초 남음 · 약 74라운드 · 전체 10분 · 턴 끝에 끝남 · 지속 필요". 1라운드 남으면 테두리가 깜빡입니다.
- 새 설정은 모두 HUD 설정 창의 **캐릭터 HUD**(효과 시간·반응 점·지속 주문·모두 적용)와 **채팅창 › 긴 세션** 탭에 있습니다.

## v1.13.0 — 기술 창 · 반응 카드 한 장 · 효과 테두리 · 채팅 초상화

- **기술 창**: HUD 바의 체크리스트 버튼. 모든 기술과 기술 행동(지각 포함)이 한 화면에 — 기술 이름을 누르면 판정, 행동을 누르면 그 행동(PF2e 행동 매크로),
  작은 칩으로 변형(주의 분산 · 공연 …)과 2·3번째 공격(다중공격 페널티 −5/−10, 민첩 −4/−8). 훈련이 필요한 행동은 미훈련이면 흐리게(「미훈련 행동 숨기기」),
  마우스를 올리면 설명. 위쪽 「전문가 따르기」로 탐험 효과를 켜고 끕니다. 지식 기술도 아래에.
- **반응 알림: GM 카드는 턴마다 한 장.** 같은 턴에 생긴 반응 기회(여러 이동, 여러 공격)는 한 카드에 사건별로 모이고, 새 사건이 생기면 그 카드가 맨 아래로 다시 올라옵니다.
  한 생물이 리액션을 다 쓰면 그 생물의 다른 줄은 「남은 리액션 없음」으로 닫히고, 다음 턴이 지나면 답하지 않은 줄은 「턴이 지나감」으로 닫힙니다. 플레이어 카드는 그대로.
- **효과 시간 테두리**: 아이콘 테두리 바깥에 얇은(2px) 하늘색 링 — 25% 이하면 주황, 마지막 라운드면 빨강. 겹치지 않게 간격도 넓혔습니다.
- **채팅 초상화**: NPC만 원형 링 토큰으로 바꾸고, PC는 원래 토큰 그림을 그대로 작게(잘리지 않게) 보여 줍니다.
- 캐릭터 빌더(새 모듈 Rutz's PF2e Character Builder)가 켜져 있으면 HUD 바에 망치 버튼.
